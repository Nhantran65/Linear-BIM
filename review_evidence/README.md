# Linear-BIM numerical review evidence

`paper_v1.json` is a deterministic 34 KB export for the supplied `Linear_BIM_Paper.pdf` (SHA-256 is in the JSON). It contains aggregate confusion matrices, fold counts of correct predictions, parameter/operation ledgers, aggregate intervention matrices, subject-level *derived* differences and medians for bootstrap checks, learned time constants, and the eight published Figure 2 margin contributions. It contains no input signals, epoch predictions, embeddings, model weights, or trial-level records.

Run `python scripts/check_review_evidence.py` from the repository root after installing NumPy. It computes ACC, macro-F1, N1 F1 and Cohen's kappa from the matrices, matched gains and fold directions, Table II interventions, the Figure 2 margin identity, and the paper's subject-cluster bootstrap intervals using the original seeds and 10,000 draws. `--check-sources` also verifies SHA-256 for any listed source files present locally. Missing source files are expected in a clean clone. To regenerate the bundle in the full research workspace, run `python scripts/export_review_evidence.py`; this reads ignored frozen reports and attribution arrays.

**Scope:** this checks arithmetic and provenance of selected, already-produced evidence. The pooled event-level history-share medians (75.81%, 81.92%, 65.42%, 78.00%) and exact residual errors are carried as report claims; the available compact subject summaries cannot independently reconstruct pooled event medians or replay logits. External-method rows in Table I are literature values. Recreating them, training checkpoints, preprocessing records, and rerunning evaluation requires original datasets, frozen outputs, weights, and historical runners. Sleep-EDF BIM checkpoints were selected by held-out accuracy under recording-wise splits with subject overlap; the results are not clean outer-test estimates.
